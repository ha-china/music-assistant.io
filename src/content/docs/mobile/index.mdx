# 移动设备

## 通知屏幕支持

当您在现代浏览器中访问 Music Assistant 界面时，将在设备的通知屏幕或锁屏界面看到一个媒体播放器小部件（这使用了浏览器的 <a href="https://caniuse.com/?search=mediasession" target="_blank" rel="noopener noreferrer">Media Session 功能</a>）。支持暂停、播放、下一曲和上一曲功能。

虽然已测试此功能在使用 iOS Home Assistant 应用访问 Music Assistant 界面时有效，但 Android 版 Home Assistant 应用尚无法保证相同的效果。如果您想在 Android 设备上使用此功能，请使用受支持的浏览器。

Android 用户还应注意，在远程设备上观察播放时，可能会看到“This Phone”标签。这是 Android 操作系统的限制。

如果未看到媒体播放器小部件，则需要使用其他受支持的浏览器。
