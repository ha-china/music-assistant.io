# 插件

插件添加的是与播放并行运行、而非作为播放一部分的功能。

[音乐源（music source）](/music-providers/)负责把音乐引入。[播放器提供程序（player provider）](/player-support/)负责把音乐发送到扬声器。而插件做的完全是另一类事情：它可以举办一场派对，让你的客人从中点播曲目；可以在电视上运行音乐问答游戏；可以让其他应用通过 AirPlay 或 DLNA 把音频发送*到* Music Assistant；或者把你播放过的内容上报给 Last.fm。

插件是可选的。即使一个插件都没有，Music Assistant 也能运行得非常好。

## 添加插件

前往 **设置 → 插件 → 添加插件**，然后从列表中选择一个。每个插件在本节中都有自己的页面，介绍它的功能以及如何配置。

有些插件依赖于先设置好其他东西。例如，[Home Assistant](/ha-plugin/) 插件需要一个它可以连接的 Home Assistant 实例。

## 所有插件

每个插件都按其用途进行了分组。每个插件都有自己的详情页面。
