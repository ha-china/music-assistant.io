# 用户管理 <img src="/assets/icons/user-management-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

此页面用于管理用户及其角色和权限。

## 管理用户

每个用户名的右侧都有一个 ⋮ 菜单，其中包含四个菜单项

- <b>编辑用户。</b>请参见下方的章节
- <b>管理访问令牌。</b>允许管理登录会话和长期令牌，方式与个人[个人资料设置](/settings/profile/)页面中显示的相同
- <b>禁用用户。</b>阻止用户访问。设置将被保留
- <b>删除用户。</b>彻底删除用户及其所有设置

## 编辑用户

![Preview image](/assets/screenshots/edit-user.png)

上方所示的对话框会在点击用户名或通过 ⋮ 菜单时出现。

每个用户都可以被限制使用特定的一组播放器（player）。受限制的用户会自动获得对其个人资料所关联的任何新浏览器窗口、桌面应用或移动伴侣应用播放器的访问权限。此外，将用户限制为某些音乐源还有两个好处：发起播放时只会使用这些音乐源，并且收听统计能够准确归因于用户的音乐源流媒体账户。

> [!CAUTION]
> 当音乐源从 MA 中移除时，任何将其作为限制的用户中的相应条目都会被清理。但是，如果这导致用户不再有任何音乐源限制，那么他们将能够访问完整的媒体库。

### 多用户环境中的有声读物和播客进度同步

<a name="filter-progress-multi-user"></a>
某些播客和/或有声读物音乐源，例如 [Audiobookshelf](/music-providers/audiobookshelf/)、[Audible](/music-providers/audible/) 和 [Storytel](/music-providers/storytel/)，支持同步媒体项的进度。通过音乐源筛选功能将此类音乐源仅分配给某个特定用户，进度便只会与该用户同步，而不是与所有用户同步。通过多次设置这些音乐源，并通过筛选功能正确分配音乐源，即可实现针对单个用户的同步。
