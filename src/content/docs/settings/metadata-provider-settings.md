# 元数据提供商设置 <img src="/assets/icons/metadata-general-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

元数据（metadata）是 Music Assistant 围绕您的音乐所展示的一切内容：封面图片、艺人简介、流派、歌词等。可供使用的元数据提供商有很多，本页面即是添加和配置它们的地方，路径为 **设置 → 元数据提供商**。

其中一些随 Music Assistant 附带提供，在您进行任何操作之前就已处于工作状态：

| 提供商 | 提供的内容 |
|:--|:--|
| MusicBrainz | 识别艺人、专辑和曲目，使同一项目在您的各音源之间相互匹配 |
| Playlist Metadata | 为您的媒体库播放列表生成封面图片和流派 |
| Fanart.tv | 艺人和专辑图片 |
| The Audio DB | 简介、描述、流派、厂牌和图片 |
| Cover Art Archive | 专辑正面封面 |
| iTunes Artwork | 高分辨率专辑封面 |
| LRCLIB | 同步歌词和纯文本歌词 |
| Genius Lyrics | 非同步歌词，作为备用来源 |
| Wikipedia | 以您的首选语言提供的艺人简介 |

MusicBrainz 和 Playlist Metadata 为内置提供商，无法关闭。其余的可以在此处逐个禁用，也可以通过 [系统设置](/settings/core/#metadata) 中的“启用从在线元数据提供商获取元数据”选项一次性全部禁用。

其他提供商，例如 [LastFM 推荐](/metadata-providers/lastfm-recommendations/)，则像添加音乐源一样在此处添加。

有关每个提供商提供的内容、查询何时发生，以及如何修复缺失的封面图片或艺人信息，请参阅 [元数据概览](/metadata/)。
