# 播放器提供程序设置 <img src="/assets/icons/settings-players-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

所有播放器提供程序（Player Provider）都有可配置的设置。设置页面的外观与下图类似。右上角的问号图标是指向本文档中相关页面的超链接。针对某个设置或可配置字段的特定帮助通常可用，点击此图标 ![image](/assets/icons/question-mark.png) 即可访问。所有提供程序都可以设置自定义名称，并在必要时禁用。所有提供程序的日志级别均可调整，可在高级设置中找到。（除非开发人员要求，否则不要选择 Verbose，因为它可能会对性能产生不利影响）。有关提供程序特定设置（许多提供程序没有此类设置），请参阅相应的提供程序页面，以及[单个播放器设置](/settings/individual-player/)页面。
