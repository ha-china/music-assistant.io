# MA transfer_queue 动作

> [!NOTE]
> 此动作用于 Home Assistant 脚本和自动化中，并且需要 [Home Assistant 集成](/integration/installation/)。有关示例，请参见 [Home Assistant 脚本和自动化](/faq/how-to/#home-assistant-scripts-and-automations)。


此动作允许您将一个播放器的队列转移到另一个播放器。您也可以在应用中直接从[正在播放视图](/ui/#now-playing-view)的 ⋮ 菜单转移队列。
