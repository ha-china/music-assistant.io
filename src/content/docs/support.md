# 支持 <img src="/assets/icons/support-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

由于本项目源自一个 Home Assistant 集成（integration），所有最终用户支持均在单独的仓库中维护。请<a href="https://github.com/music-assistant/support" target="_blank" rel="noopener noreferrer">在此</a>提交问题并讨论想法

直接链接如下：

- <a href="https://github.com/music-assistant/support/issues" target="_blank" rel="noopener noreferrer">问题追踪器</a>：用于创建错误报告。请先查阅[故障排除](/faq/troubleshooting/)页面，检查您的问题是否已被报告过。提交报告时请附上详细信息和日志文件。
- <a href="https://github.com/orgs/music-assistant/discussions/categories/feature-requests-and-ideas" target="_blank" rel="noopener noreferrer">功能请求</a>：为现有请求投票、参与讨论或添加新请求。
- <a href="https://github.com/orgs/music-assistant/discussions/categories/q-a" target="_blank" rel="noopener noreferrer">问答区</a> 常见问题和教程

 此外，您还可以在 <a href="https://discord.gg/kaVm8hGpne" target="_blank" rel="noopener noreferrer">discord 社区</a>中寻求帮助。加入社区并获取支持！

**提问之前：**

请阅读<a href="http://www.catb.org/esr/faqs/smart-questions.html" target="_blank" rel="noopener noreferrer">《提问的智慧》</a>

在任何支持渠道中提出技术问题之前，请先执行以下操作：

1. 尝试通过搜索本文档和<a href="https://github.com/orgs/music-assistant/discussions" target="_blank" rel="noopener noreferrer">讨论区</a>来寻找答案
2. 尝试通过搜索<a href="https://github.com/music-assistant/support/issues?q=is%3Aissue+is%3Aclosed" target="_blank" rel="noopener noreferrer">已关闭的问题</a>来寻找答案
3. 尝试通过搜索网络来寻找答案：https://www.google.com/
4. 尝试通过检查或实验来寻找答案。
5. 尝试通过请教有经验的朋友来寻找答案。

当您提问时，请表明您已经做过这些事情；这将有助于证明您并非懒惰、浪费他人的时间。更好的做法是，展示您从这些尝试中学到了什么。我们乐于为那些已经证明自己能够从答案中学习的人解答问题。
