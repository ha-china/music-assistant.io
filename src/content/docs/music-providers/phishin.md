# Phish.in <img src="/assets/icons/phish-logo.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

Music Assistant 支持 <a href="https://phish.in/" target="_blank" rel="noopener noreferrer">Phish.in</a>。该组件由 <a href="https://github.com/ozgav" target="_blank" rel="noopener noreferrer">Gavin</a> 贡献并维护

Phish.in 为乐迷提供了一个全面的平台，用于发现、流媒体播放和分享乐队 Phish 的现场观众录音，Phish 以其即兴摇滚音乐而闻名。

该音源（source）可免费使用，无需账户。此音源将这些录音以专辑的形式呈现在 Music Assistant 中，因此您可以像浏览和播放媒体库中的其他内容一样，浏览和播放整场演出。

## Features

|           |                     |
|:-----------------------|:---------------------:|
| Subscription FREE | Yes |
| Self-Hosted Local Media | No |
| Media Types Supported | Artists, Albums, Tracks, Playlists |
| [Recommendations](/ui/#view---discover) Supported | No |
| Lyrics Supported | No |
| [Endless Mix](/ui/#track-menu) | No |
| Artist Top Tracks Support                       |            Yes                     |
| Similar Artists Support                         |            No                      |
| Similar Tracks Support                          |            No                     | 
| Maximum Stream Quality | MP3 256kbps |
| Login Method | None |

### Other

- Stream all Phish concerts from 1983-present with available audio
- Browse 1,800+ shows organized as albums in Music Assistant
- Access 50,000+ individual track performances
- Search for concerts, tracks and playlists by partial title

## 配置：

在配置中，您只需点击保存按钮即可。

## 已知问题 / 说明

- 一些早期演出的音频不完整或缺失
- 媒体库视图有 2500 个条目的限制，以保持界面的响应速度
- 搜索仅支持标题匹配（不支持模糊搜索或高级查询）
- 播放列表为只读。可访问来自 Phish.in 社区的用户创建播放列表
- 可按年份、场馆、标签、历史上的今天、最受喜爱的演出和曲目、用户播放列表以及随机表演浏览曲库
