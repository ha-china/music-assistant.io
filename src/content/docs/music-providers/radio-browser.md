# Radio Browser <img src="/assets/icons/radiobrowser_icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

Music Assistant 支持 <a href="https://www.radio-browser.info/" target="_blank" rel="noopener noreferrer">RadioBrowser</a>，可以将在线电台轻松添加到 Music Assistant。

Radio Browser 是一个由社区运营的免费目录，收录了来自世界各地的网络电台。任何人都可以添加电台，且整个数据库是开放的，这使其成为查找你已在收听的电台直播流的最简单方式。

此来源使该目录可以在 Music Assistant 中进行搜索，因此其中的任何电台都可以播放并保存到你的电台列表中。

## 配置

在配置中，你只需点击保存按钮。

## 用法

电台提供器（provider）默认不会将电台添加到 'radiostation' 标签页中。

1. 在左侧菜单中，你需要选择 'browse'（浏览）
2. 然后点击 'RadioBrowser'

    <img src="/assets/screenshots/IMG_1181.jpeg" alt="Preview image" style="width: 400px;"  loading="lazy" />

3. 然后导航到你想要收听的电台
4. 点击立即播放或添加到资料库

完成第 4 步后，该电台将出现在电台视图中。

## 已知问题 / 注意事项

在浏览各个 Radio Browser 分类时，结果仅限于前 1000 条。对于包含超过 1000 个电台的分类，请使用搜索功能。
