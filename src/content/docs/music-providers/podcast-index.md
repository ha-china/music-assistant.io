# Podcast Index <img src="/assets/icons/podcast-index-icon.png" alt="Preview image" style="width: 70px; float: right;"  loading="lazy" />

Music Assistant 支持流媒体播放来自 <a href="https://podcastindex.org/" target="_blank" rel="noopener noreferrer">Podcast Index</a> 的播客。由 <a href="https://github.com/ozgav" target="_blank" rel="noopener noreferrer">Gavin</a> 贡献并维护

Podcast Index 是一个免费且开放的播客源（feed）目录，以非营利方式运营，依靠捐赠维持。任何人都可以添加播客源，任何人都可以进行搜索，没有中间公司来决定哪些内容会被收录。

通过该音源，您可以在 Music Assistant 中搜索和浏览该目录，并将找到的任何内容添加到您的媒体库中。

## 配置

您需要从 https://api.podcastindex.org/signup 获取 API key 和 API secret

### 设置

- <b>API Key</b> 在此处输入您的 API key
- <b>API Secret</b> 在此处输入您的 API secret
